POST/api/upload

参数位置必填说明
fileform是支持的图片文件
nameform否展示名称，缺省取文件名
visibilityform否public（默认）或 private
team_idform否团队空间 ID，调用者必须是成员
import os
from pathlib import Path
import requests

base = os.getenv("OSS_BASE_URL", "{{BASE}}")
headers = {"Authorization": f"Bearer {os.environ['OSS_TOKEN']}"}
path = Path("cover.png")
with path.open("rb") as stream:
    response = requests.post(
        f"{base}/api/upload",
        headers=headers,
        files={"file": (path.name, stream)},
        data={"name": "项目封面"},  # visibility 缺省即 public
        timeout=120,
    )
response.raise_for_status()
print(response.json())
curl --fail-with-body -X POST "$OSS_BASE_URL/api/upload" \
  -H "Authorization: Bearer $OSS_TOKEN" \
  -F "file=@cover.png" \
  -F "name=项目封面"

GET/api/media/{code}/link

参数必填说明
code是媒体短码
ttl否有效秒数，受服务端最大值限制
import os
import requests

base = os.getenv("OSS_BASE_URL", "{{BASE}}")
code = "Ab3xYz9Kq1"
token = os.getenv("OSS_TOKEN")
response = requests.get(
    f"{base}/api/media/{code}/link",
    headers={"Authorization": f"Bearer {token}"} if token else {},
    params={"ttl": 3600},
    timeout=30,
)
response.raise_for_status()
print(response.json()["url"])
# 公开媒体：匿名返回规范直链
curl --fail-with-body "$OSS_BASE_URL/api/media/Ab3xYz9Kq1/link?ttl=3600"

# 私密媒体：有权 JWT 或 API Key 返回签名链接
curl --fail-with-body \
  "$OSS_BASE_URL/api/media/Ab3xYz9Kq1/link?ttl=3600" \
  -H "Authorization: Bearer $OSS_TOKEN"

POST/api/video-uploads

字段必填说明
filename / size / fingerprint是原文件名、字节数、64 位十六进制快速指纹
name否展示名
visibility否public（默认）或 private
team_id否有权团队 ID
import hashlib
import os
from pathlib import Path
import requests

path = Path("movie.mp4")
size = path.stat().st_size
sample_size = 1024 * 1024
offsets = [0, max(0, size // 2 - sample_size // 2), max(0, size - sample_size)]
with path.open("rb") as stream:
    hashes = []
    for offset in offsets:
        stream.seek(offset)
        hashes.append(hashlib.sha256(stream.read(sample_size)).hexdigest())
fingerprint = hashlib.sha256(f"{size}:{':'.join(hashes)}".encode()).hexdigest()

base = os.getenv("OSS_BASE_URL", "{{BASE}}")
response = requests.post(
    f"{base}/api/video-uploads",
    headers={"Authorization": f"Bearer {os.environ['OSS_TOKEN']}"},
    json={"filename": path.name, "size": size, "name": "发布会录像", "fingerprint": fingerprint},
    timeout=30,
)
response.raise_for_status()
session = response.json()
print(session["upload_id"], session["chunk_size"], session["uploaded_parts"])
curl --fail-with-body -X POST "$OSS_BASE_URL/api/video-uploads" \
  -H "Authorization: Bearer $OSS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"filename":"movie.mp4","size":8388608,"name":"发布会录像","fingerprint":"替换为64位快速指纹"}'

PUT/api/video-uploads/{upload_id}/parts/{part_number}

import hashlib
import os
from pathlib import Path
import requests

base = os.getenv("OSS_BASE_URL", "{{BASE}}")
upload_id = os.environ["OSS_UPLOAD_ID"]
auth = {"Authorization": f"Bearer {os.environ['OSS_TOKEN']}"}
session = requests.get(f"{base}/api/video-uploads/{upload_id}", headers=auth, timeout=30).json()
part_number = 0
start = part_number * session["chunk_size"]
with Path("movie.mp4").open("rb") as stream:
    stream.seek(start)
    chunk = stream.read(session["chunk_size"])
end = start + len(chunk) - 1
headers = {
    **auth,
    "Content-Type": "application/octet-stream",
    "Content-Range": f"bytes {start}-{end}/{session['size']}",
    "X-Chunk-SHA256": hashlib.sha256(chunk).hexdigest(),
}
response = requests.put(
    f"{base}/api/video-uploads/{upload_id}/parts/{part_number}",
    headers=headers,
    data=chunk,
    timeout=120,
)
response.raise_for_status()
curl --fail-with-body -X PUT \
  "$OSS_BASE_URL/api/video-uploads/$OSS_UPLOAD_ID/parts/0" \
  -H "Authorization: Bearer $OSS_TOKEN" \
  -H "Content-Type: application/octet-stream" \
  -H "Content-Range: bytes 0-8388607/8388608" \
  -H "X-Chunk-SHA256: 替换为当前分片SHA256" \
  --data-binary @part-0

方法路径权限与用途
GET/api/auth/config公开客户端上传、会话、并发与容量限制
GET/api/keysJWT-only：列出自己的 API Key 前缀
POST/api/keysJWT-only：创建仅展示一次的 API Key
GET/api/images?limit&offset&q&scopescope=mine 为当前账号个人空间；scope=all 为仅管理员 JWT 可用的全站视图
GET/api/media/{code}公开媒体匿名元数据（隐藏属主、团队和原文件名）；私密媒体仅有权身份可读，越权返回 404
GET/api/media/{code}/link?ttl=3600公开媒体可匿名取得规范直链；私密媒体需有权 JWT/API Key 并返回限时签名链接
PATCH/api/images/{code}更新名称或可见性
DELETE/api/images/{code}属主、团队管理员或管理员 JWT 删除；管理员 API Key 无全局越权
GET/api/video-uploads找回当前用户可续传会话及动态并发上限
DELETE/api/video-uploads/{upload_id}取消未完成会话，不删除已发布视频
GET/api/videos?limit&offset&q&scopescope=mine 为当前账号个人空间；scope=all 为仅管理员 JWT 可用的全站视图
PATCH/api/videos/{code}更新名称或可见性
GET/api/media-groupsJWT-only：个人或有权团队分组与 items 管理
GET/api/teams/{id}/imagesJWT / API Key：有权团队成员；仅管理员 JWT 可全局越权
GET/api/teams/{id}/videosJWT / API Key：有权团队成员；仅管理员 JWT 可全局越权

个人空间列表、修改、删除和上传会话均绑定当前身份；普通成员不能通过传 owner_id 查看他人资产。
团队空间team_id 不是授权凭据。每次调用仍校验团队成员关系；管理操作要求 owner/admin。
私密媒体只允许属主、有权团队成员、管理员 JWT 或有效签名 URL；管理员 API Key 仍按属主/团队范围，其他请求返回 404。
公开参数visibility 缺省为 public；只有显式传 private 才进入私密访问规则。切勿让不可信调用方随意传 team_id。

API Key 绑定用户但仅用于媒体数据面，且管理员 API Key 不继承管理员 JWT 的全局越权能力。修改密码、管理 Key、创建/管理团队、管理分组、用户与管理员接口必须使用 JWT；不要把令牌、X-API-Key、签名链接的 sig 或完整查询串写入日志、工单和截图。

方法路径说明
GET/api/admin/statsJWT-only：用户、媒体、团队与存储总览
GET/api/admin/traffic-stats?days=7JWT-only：1–365 天请求数量、请求/响应流量、路由、API Key 与成员空间统计
GET/healthz轻量存活检查
GET/readyzSQLite 写探针、数据目录落盘与磁盘空间检查
GET/openapi.json机器可读 OpenAPI 规范
所有响应包含 X-Request-ID，排查问题时可提供该值。部署反代必须保留 Range 相关请求/响应头。
